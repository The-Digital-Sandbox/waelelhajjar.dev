pub fn sign(secret_key: &[u8], message: &[u8])
    -> Result<Vec<u8>, CryptoError> {
    let secret = SecretKey::from_bytes(secret_key)
        .map_err(|_| CryptoError::InvalidKeyLength)?;
    let public = secret.to_public();
    let ctx = signing_context(SIGNING_CONTEXT);
    let sig = secret.sign(ctx.bytes(message), &public);
    Ok(sig.to_bytes().to_vec())
}

01

Spondula, a global payments network. Founder and engineer, 2025 to now. Live in beta since June 2026 on the App Store and Google Play.

Send to a handle. One implementation of the maths underneath.

Your S-Handle is your payment identity, the payment equivalent of a username. You share it instead of account numbers, sort codes, IBANs or wallet addresses, and transfers between handles on the network are free. The recordings on the right are the real iOS app: a send, and a payment inside a chat.

Nine repos, most of them mine end to end: a TypeScript web wallet and gateway, an admin console, a merchant gateway, a status page, an article studio, a Kotlin and Compose Android app, a SwiftUI iOS app, and a Rust ledger underneath. Alongside them a motion kit in Remotion whose compositions are prop-driven templates, so the teaser in the third tab is rendered from data, not edited by hand.

The decision I would defend hardest is the signing core. A wallet that signs payments on two platforms should have one implementation of the maths, so key derivation, signing and addresses are one Rust crate exposed to Swift and Kotlin through UniFFI, with the golden vector pinned at three layers and the signature path cross-checked against the reference JavaScript implementation. Public as sr25519-uniffi.

02

Reverse engineering Crimson Desert's skinned-mesh format, 2026. Public repo, MIT.

The engine does not store 3D positions at all.

The format is undocumented and every existing extractor gave up on it. The reason turned out to be that the file holds no positions. The vertex shader reconstructs them at runtime from six quantised bytes per vertex and a bounding box per submesh, which I found by tracing a single draw in PIX and reading the compiled shader.

The figure shows what that means. Drag the precision down and watch the surface snap to a coarser grid: the mesh only ever exists as a fraction of its bounding box. From that finding came a codec that decodes and re-encodes the format, patchers that redirect assets to a staging directory so the game's own files are never touched, and CPU replays of the shader stages checked against the capture until the residual was explained.

The repo also keeps the approaches that looked right and were wrong, so nobody repeats them. The C++ loader DLL that hooks the game's file API is a separate project.

03

Thursday, a personal chief of staff, and vault-brain, its memory pipeline, released on its own.

A memory it maintains itself.

Thursday answers on WhatsApp and email. Behind it is a Node server with a React ops deck, a headless CLI runner for the model with per-thread session continuity, and a morning brief, an end-of-day review and an obligation ledger that run without being asked.

The part worth publishing is how it remembers. An agent that remembers across sessions needs its memory maintained, not just appended. Three stages run nightly over a markdown vault, and the figure runs them on the toolkit's own test fixture: walk the day's captures into typed atoms on entity notes, reconcile duplicate entities and repoint every link, then type the relationships and promote well-connected notes into insight hubs. Ledgers make each stage idempotent, a budget governor can skip a night, and the model is any command that reads a prompt on stdin. No dependencies, 51 tests.

Before and alongside Spondula: The Digital Sandbox, Autotube, Fincore.

Products, and one prototype.

The Digital Sandbox is a customer-messaging platform for small businesses: an embeddable chat widget, campaigns and flows, Meta integrations for Facebook, Instagram and WhatsApp, and a React Native companion app. Next.js, deployed on Google Cloud. The browser on the right is the live site, not a screenshot.

Autotube is a multi-tenant short-video generator. Brand configuration drives the Remotion compositions, so one video engine serves every tenant with their own fonts, colours and presenter overlays, on top of tenant-scoped data rules and a render job queue.

Fincore is the prototype: a fintech app that reads your Big Five personality profile and reframes spending decisions through it. 38 screens in Next.js and an Expo twin. Swipe through five of them below the browser.
