01

Spondula, a global payments network. Founder and engineer, 2025 to now.

One implementation of the maths, not two.

Spondula is a global payments network where your S-Handle is your payment identity, the payment equivalent of a username. You share it instead of account numbers, sort codes, IBANs or wallet addresses. Transfers between S-Handles on the network are free. It has been live in beta since June 2026 and is on the App Store and Google Play.

Nine repos, most of them mine end to end: a TypeScript web wallet and gateway, an admin console, a merchant gateway, a status page, an article studio, a Kotlin and Compose Android app, a SwiftUI iOS app, and a Rust ledger underneath. Alongside them a motion kit in Remotion whose compositions are prop-driven templates, so a corridor teaser is rendered from data rather than re-edited.

The decision I would defend hardest is the signing core. A wallet that signs payments on two platforms should have one implementation of the maths. So the key derivation, signing and address code is one Rust crate exposed to Swift and Kotlin through UniFFI, with the golden vector pinned at three layers and the signature path cross-checked against the reference JavaScript implementation. That crate is public as sr25519-uniffi.

02

Reverse engineering Crimson Desert's mesh format, 2026. Public repo, MIT.

The engine does not store 3D positions at all.

The game's skinned-mesh format is undocumented, and every existing extractor gave up on it. The reason turned out to be that the file holds no positions. The vertex shader reconstructs them at runtime from quantised bytes and a per-submesh bounding box stored in the descriptor. I found that by tracing a single draw in PIX and reading the compiled shader.

From there: a codec that decodes and re-encodes the format, patchers that redirect assets to a staging directory so the game's own files are never touched, and CPU replays of the shader stages that are checked against the capture stage by stage until the residual is explained. The C++ loader DLL that hooks the game's file API is a separate project.

The repo also keeps the approaches that looked right and were wrong, so nobody repeats them.

03

Thursday, a personal chief of staff, and vault-brain, its memory pipeline, released on its own.

A memory it maintains itself.

Thursday answers on WhatsApp and email. Behind it is a Node server with a React ops deck, a headless CLI runner for the model with per-thread session continuity, and a morning brief, an end-of-day review and an obligation ledger that run without being asked.

The part worth publishing is how it remembers. An agent that remembers across sessions needs its memory maintained, not just appended. Three nightly stages run over a markdown vault: walk the day's session captures into typed atoms on entity notes, reconcile duplicate entities and repoint every wikilink, then type the relationships between notes and promote well-connected ones into insight hubs. Ledgers make every stage idempotent, a budget governor can skip a night, and the model is any command that reads a prompt on stdin. No dependencies, 51 tests.

Before and alongside Spondula: The Digital Sandbox, Autotube, Fincore.

Products, not prototypes. One prototype.

The Digital Sandbox is a customer-messaging platform for small businesses: an embeddable chat widget, campaigns and flows, Meta integrations for Facebook, Instagram and WhatsApp, and a React Native companion app. Next.js, deployed on Google Cloud.

Autotube is a multi-tenant short-video generator. Brand configuration drives the Remotion compositions, so one video engine serves every tenant with their own fonts, colours and presenter overlays, on top of tenant-scoped data rules and a render job queue.

Fincore is the prototype: a fintech app that reads your Big Five personality profile and reframes spending decisions through it. 38 screens in Next.js and an Expo twin. The splash is rendered to video by Remotion from the same component that draws it in the app, so the two can never disagree.
